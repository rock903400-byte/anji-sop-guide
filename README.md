## ✨ 系統特色

1. **任務導向直覺選單**：依手頭業務直接點選「新加保（現金／備轉金／應付代收）」、「年度續保與修改資料」、「合併送件＋送協會＋請款」、「協會核保通過後自動沖銷結案」或「常見問題排除指南」。
2. **「應付代收」跨模組流程自動順排**：自動將 `會計作業開立傳票 (P.112~119)` ➔ `安基作業加保建檔 (P.13~17, P.120)` ➔ `會計作業傳票確認 (P.121~124)` 排成一直線，避免結餘顯示為 0 的常見卡關。
3. **關鍵「請主管審核」與「切換系統模組」醒目提醒**：在每個需要主管放行或切換模組的節點提供明確提示。
4. **手機與 LINE 內建瀏覽器專屬優化**：支援置底拇指導航列、左右滑動切換步驟、以及截圖 200% 放大滑動檢視。
